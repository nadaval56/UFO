# תרגומים עבריים — תהליך עבודה

תיאורי הקבצים בעברית (`summary_he`) ב-`manifest.json` נכתבים ידנית בקלוד קוד (לא דרך Anthropic API). הסיבה: שמירה על תרגום נאמן, מבוקר, ובלי לחייב את חשבון ה-API.

## תהליך

1. `scripts/build_manifest.py` רץ ב-CI ושומר תיאורים באנגלית מתוך war.gov לתוך `manifest.json` כשדה `summary_en`.
2. `summary_he` נשאר `null` עבור רשומות חדשות.
3. כדי להוסיף תרגומים, פתח Claude Code בריפו וקרא:
   > "תרגם בעברית נאמנה את כל ה-summary_en שעדיין חסרים להם summary_he ב-data/manifest.json. שמור על יחס אורך מקור-לתרגום ≈ 1:1; אל תקצר ואל תפרש. עדכן את הקובץ במקום."
4. הסקריפט (`build_manifest.py`) משמר את ה-`summary_he` הקיים על פני ריצות עתידיות, כך שתרגום לא הולך לאיבוד.

## כללי תרגום

- **שמור על קודי תיק כפי שהם:** `62-HQ-83894`, `HS1-834228961`.
- **שמות גיאוגרפיים:** תעתיק עברי (`אוק רידג', טנסי`).
- **תאריכים:** עברית מילולית (`יוני 1947 ליולי 1968`), לא פורמט מספרי.
- **ראשי תיבות:** השאר באנגלית במקור (FBI, UAP, UFO).
- **אורך:** קרוב למקור. עברית בדרך כלל 80–95% מאורך המקור באנגלית.

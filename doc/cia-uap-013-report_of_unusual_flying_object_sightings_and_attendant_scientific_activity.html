1956, בודפשט, הונגריה — דו"ח מידע של ה-CIA משנת 1956 המתאר תצפיות עצמים מעופפים שדווחו על ידי מקור-משנה שמושבו בבודפשט, ובכלל זה שרטוט המראה את מבנה הטיסה המשוער של העצמים ואת מסלולם בין בודפשט למוסקבה. גרסה מצונזרת יותר של הדו"ח הייתה זמינה באתר הציבורי של ה-CIA.

// תקציר רשמי

מתוך התיאור הרשמי של war.gov.

הצגת המקור באנגלית
This 1956 CIA Information Report describes flying object sightings reported by a Budapest-based sub-source, including a sketch showing the objects' suspected formation and flight path between Budapest and Moscow. A more redacted version of this report has been available on CIA's public website.

מס' עמודים: 1

תאריך המידע: נובמבר 1955

זהו מידע בלתי מוערך.

מקור: אזרח אמריקאי מהתאזרחות, ממוצא הונגרי. הוא מתכתב באופן קבוע עם שתי אחייניות המתגוררות בבודפשט.

1. בנובמבר 1955 קיבלתי מכתב מאחייניתי בבודפשט. מכתב זה הכיל את הפריט המעניין הבא [תרגום חופשי]:

"מה שמכונה צלחות מעופפות (רקטות) החזיקו במשך שבועות אחדים את האנשים במצב עצבני. הטסים המהירים והמאיצים הללו העסיקו מאוד קבוצות מדעיות. אני בטוחה ששמעת כבר מהעיתונים, 12 אלף ק"מ לשעה נאמד למעופפים הללו."

2. יחד עם המכתב צורף השרטוט הבא המציין את המבנה והמסלול המשוער של העצמים הנ"ל:
בודפשט: [—]
מוסקבה

3. זו הפעם הראשונה שאחייניתי מזכירה עצמים כאלה במכתביה.

4. [ניתן להשאלה מספריית ה-CIA עותק פוטוסטטי של המכתב המקורי בהונגרית וכן תרגום לאנגלית. הקטע המצוטט בפסקה 1 מסומן בסוגריים במכתב זה.] בלתי מסווג.

NOFORN. אין להפיץ בחו"ל.
מוגבל: ההפצה מוגבלת לעובדים במשרה מלאה של CIA, AEC ו-FBI; ובתוך משרד החוץ והביטחון, לרכיבי המודיעין, למשרדים אחרים המפיקים רכיבי NIS, ולדרגים גבוהים יותר יחד עם צוותי התמיכה המיידיים שלהם. אין להפיצו ליועצים, לפרויקטים חיצוניים או לאנשי מילואים בשירות פעיל קצר מועד (למעט יחידים שהם בדרך כלל עובדים במשרה מלאה של CIA, AEC, FBI, משרד החוץ או הביטחון), אלא אם התקבל אישור בכתב מהמשרד המקורי באמצעות סגן המנהל לאיסוף והפצה, CIA.
